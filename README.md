## v2.5 — APK v1.3.0: Firestore live sync, NO token (2026-11-11, user order)

Status line at the top of Settings ("☁️ Live — saved to all apps HH:MM:SS" / "⚠️ Offline — saved on this device, will retry"), plus a manual "↻ Pull latest from cloud" button and retry on the `online` event.
